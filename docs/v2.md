# Pipeline v2 (development line)

- **Started:** 2026-11-09
- **What it is:** the v1 pipeline plus a text clean-up step that runs before extraction, aimed at messier notes. Code: `src/resauce/v2/`.
- **Status:** architecture and workstation support only. No clean-up rule that reads clinical wording exists yet, and v2 has not been scored on any data.

## Rules for this line

1. **v1 is untouched.** The seven frozen files in `docs/freeze.md` do not change, and `tests/test_freeze.py` still guards them. v2 is new files only.
2. **v2 reuses v1.** It cleans each note's text, calls the v1 extractor on the cleaned text, and maps every quote back to the *original* note. The timeline, the rules engine and the scoring are v1's, fed with v2's observations.
3. **Every quote is exact original text.** v2 raises an error rather than return an observation whose quote is not the original text at the original offsets.
4. **Every change is recorded and shown.** Each edit keeps its rule, the original text and the replacement. The workstation lists them next to the note.
5. **Clinical clean-up needs a written rule first.** An abbreviation or spelling step is added only after its rule is in `docs/clinical-methods.md`, and after messy synthetic cases exist to show whether it helps. Until then v2 has only steps with no clinical meaning (stray invisible characters).
6. **No tuning on the locked set.** The locked cases (`ReSauce-locked`) are not opened while v2 is built. If v2 is later scored on the locked set, the result is reported as v2, next to v1's, with the v2 files' hashes. v1's locked result stays the pre-registered one.
7. **Results are labelled.** Any number for v2 says "v2" and says which data it was developed against. Results on synthetic data are not clinical validation.

## Limits of the design

- Steps read the original text, not each other's output, so one step cannot depend on another. Overlapping edits keep the earlier step and report the other as dropped.
- `details` and `note` on an observation come from the cleaned text. Only the evidence quotes are guaranteed to be original text.
- The timeline's copied-forward check compares original document texts, so v2 does not yet help with messy copy-forward.

## How to check it

```bash
pytest tests/test_v2.py tests/test_freeze.py
```

`test_v2.py` checks position mapping, overlap handling, an exact original quote after cleaning, and that v2 gives exactly v1's observations on the 20 dev cases when nothing needs cleaning.
